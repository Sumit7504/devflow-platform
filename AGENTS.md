# DevFlow: Hiring & Assessment Platform

## Stack (use ONLY these)
React.js, Node.js, Express.js, MongoDB, Mongoose, JWT, Socket.IO.
Allowed helpers: bcrypt, dotenv, cors, express-validator.
Do not add any other framework or library without asking me first.

## Roles
candidate, recruiter, admin.

## Structure
backend/  -> config, models, controllers, routes, middleware
frontend/ -> React app

## Code rules
- Simple, readable code with short comments on non-obvious parts.
- Structured error handling and input validation on every route.
- Work on ONE phase at a time. Show me a plan (list of files) first,
  wait for my approval, then build, then stop.

## Learning rule
After finishing each phase, add a section to LEARNING.md explaining
every file you created in simple words (what it does and why it exists).

## Design rules
- Light, simple, professional look. Use one accent color only.
- Colors: accent #0F766E (teal), background #F8FAFC, cards white,
  borders #E5E7EB, text #111827, gray text #5B6472.
- Font: Inter.
- Cards: white, thin border, rounded corners (12px), no shadows.
- Inputs 44px tall, buttons rounded (8px). Main button uses the accent color.
- No gradients, no emoji, no extra colors.
